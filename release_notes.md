# 🇵🇰 Pak Android Bloatware Remover v1.1.0 (Official Release)

Welcome to the major **v1.1.0 Pro Edition** release of **Pak Android Bloatware Remover** — the ultimate, lightweight, and safe open-source Android debloater, APK manager, and device utility for Windows.

---

## 🚀 What's New in Version 1.1.0

### 💾 1. Backup Selected APKs to PC
- **User-Selected Destination**: Extract and backup APK packages of any installed app directly to any folder on your computer (you select the exact target folder via folder picker).
- **Clean File Organization**: Backed up APKs are cleanly named as `AppName_com.package.name.apk` for easy identification.
- **Convenient Workflow**: Automatically offers to open your backup directory as soon as the extraction finishes.

### 📁 2. Batch Multi-APK Installer & Folder Ingestion
- **Multi-File Selection**: Select multiple `.apk` files at once in the file browser.
- **Install Folder of APKs**: 1-click button to select an entire folder containing APKs and install them sequentially.
- **Multi-File Drag & Drop**: Drag multiple `.apk` files or folders directly into the app window.
- **Sequential Installation Pipeline**: Visual progress counter and completion report detailing total installed packages.

### 📊 3. Live Storage & Phone Specs Dashboard
- **Storage Monitoring**: Real-time display of your phone's internal storage (e.g. `💾 42.5G Free / 128G Total`) right in the top header alongside your battery status (`🔋 85%`).
- **Live Device Telemetry**: Auto-detects manufacturer, model, Android version, serial number, and battery level.

### 📸 4. 1-Click Phone Screenshot Tool
- **High-Definition Capture**: Capture crisp, full-resolution screenshots of your phone display directly via ADB.
- **Custom Save Location**: Interactive file dialog lets you choose where to save the `.png` screenshot and what to name it.
- **Instant Preview**: Option to open and inspect the screenshot immediately upon capture.

### 🌐 5. Updated Developer & Official Service Links
- All official developer links, support desks, donation portals, terms of service, and privacy policies have been migrated to the unified official domain: `madreesdigipro.blogspot.com`.

### ⚡ 6. Core Fixes & Stability
- Added UI lifecycle guards to prevent race conditions during device initialization.
- Refined ADB binary pipe execution to ensure 100% binary integrity for APK backups and screen capture.

## 🚀 Quick Setup Guide

1. **Enable Developer Options**: Go to your phone's `Settings` ➔ `About Phone` ➔ Tap **`Build Number`** 7 times until developer mode is unlocked.
2. **Enable USB Debugging**: Go to `Settings` ➔ `Developer Options` ➔ Toggle **`USB Debugging`** ON.
3. **Connect to PC**: Connect your phone via USB cable and tap **`Allow`** on your phone screen when prompted.
4. **Run Pak Android Bloatware Remover**: Launch the app, review detected apps, and manage your device safely!

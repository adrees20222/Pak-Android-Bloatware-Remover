# 🇵🇰 Pak Android Bloatware Remover v1.2.0 (Official Release)

Welcome to the **v1.2.0 Pro Edition** release of **Pak Android Bloatware Remover** — the ultimate, lightweight, and safe open-source Android debloater, APK manager, system optimizer, and device utility for Windows.

---

## 🚀 What's New in Version 1.2.0

### ⚡ 1. System Optimizer & Junk Cleaner (No Root Required!)
Operates under Android's privileged `shell` user to execute system-level optimizations previously only possible with root:
- **🧹 Clear App Cache & Temp Junk**:
  - Triggers the official Android Package Manager cache reclamation (`pm trim-caches 999G`) to wipe temporary cache files across all installed apps without deleting user accounts, personal data, or chats.
  - Cleans staging clutter and leftover APKs in `/data/local/tmp/`.
- **⚡ Free RAM (Kill Inactive Apps)**:
  - Safely stops inactive and cached background applications (`am kill-all`), freeing system RAM and lowering device heat.
- **🚀 UI Animation Speed Scaling (Instant Phone Responsiveness)**:
  - **🚀 Fast Animations (0.5x)**: Halves all transition and window delays, making any phone feel twice as snappy and responsive.
  - **⚡ Zero Lag (0.0x - Instant)**: Removes animation delays entirely for instantaneous app opening.
  - **🔄 Default Scale (1.0x)**: Reverts system animations back to factory stock settings with 1-click.
- **🔋 Calibrate Battery Statistics**:
  - Resets accumulated Android battery drain history (`dumpsys batterystats --reset`) so the battery meter accurately recalculates runtime after debloating background apps.

## 🚀 Quick Setup Guide

1. **Enable Developer Options**: Go to your phone's `Settings` ➔ `About Phone` ➔ Tap **`Build Number`** 7 times until developer mode is unlocked.
2. **Enable USB Debugging**: Go to `Settings` ➔ `Developer Options` ➔ Toggle **`USB Debugging`** ON.
3. **Connect to PC**: Connect your phone via USB cable and tap **`Allow`** on your phone screen when prompted.
4. **Run Pak Android Bloatware Remover**: Launch the app, review detected apps, optimize your phone, and debloat safely!
